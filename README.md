# Phantom Countdown

Landing page for [Phantom Countdown](https://apps.apple.com/us/app/phantom-countdown/id1549294840), a Persona-themed countdown app. Hosted on GitHub Pages at http://supersinex.github.io/.

## Scripts

- `yarn start` runs the dev server at http://localhost:3000
- `yarn build` creates a production build in `build/` (it also copies `index.html` to `404.html` so routes like `/privacy` load on GitHub Pages)
- `yarn test` runs the tests
- `yarn deploy` builds and publishes to GitHub Pages

## Routes

- `/` is the landing page
- `/privacy` is the privacy policy linked from the App Store listing
